# Strategy Format & Layering Rules

## 策略条目格式

```markdown
### [🔴/🟡/🟢] 策略 N：策略名称

- **功能**：[一句话，达成什么传播效果]
- **适用文章类型**：[案例拆解/实操教程/短篇认知/观点复盘/深度翻译]
- **触发时机**：[在文章什么位置/读者什么状态下使用]
- **执行方式**：
  - 手法 A：[描述 + 为什么有效]
  - 手法 B：[描述 + 为什么有效]
- **成功归因**：[内容结构/表达策略/作者IP/热点事件/平台红利]（多选，标注可复制/不可复制）
- **可复制性**：高/部分/不可
- **正确用法**：[怎样算用对了]
- **常见错误**：[新策略填"待观察"。仅在后续验证中实际观察到用错实例时才填写]
- **边界**：[什么时候不该用 / 用多了会怎样]
- **来源**：[文章文件名]
`[层] 验证:N次 | 类型:A,B,C | 可复制性:X | 创建:R轮次 | 最近验证:R轮次`
```

## 分层规则

### 初始分层

新策略 → 默认 🟢 情境层

### 升级阈值

```
🟢 → 🟡：验证次数 ≥ 3 且 类型数 ≥ 2
         或 验证次数 ≥ 5（即使类型数 = 1）
🟡 → 🔴：验证次数 ≥ 8 且 类型数 ≥ 4
```

### 降级

每处理 20 篇文章后遍历所有策略：

```
最近验证轮次 距今 > 20 篇文章 → 降一级（🔴→🟡→🟢）
```

### 去重规则

新策略入库前，先检查功能是否与已有策略重复：

```
读取所有已有策略的「功能」字段
新策略的功能 ≈ 已有策略的功能？
  → 是：不新增条目。将新执行手法追加到已有策略的「执行方式」
       验证次数 +1，类型追加
       如果当前文章中该策略被用错，追加到「常见错误」
       更新最近验证，检查升级
  → 否：新增条目，默认 🟢
```

## 文章类型定义

| 类型 | 特征 | 标题模式 |
|------|------|---------|
| 案例拆解 | 讲一个人的故事/产品数据，拆解怎么做到 | "一个 X 怎么做到 Y" |
| 实操教程 | 手把手教学，有步骤和可操作指令 | "人人都能学会 X" |
| 短篇认知 | 用极简逻辑/数学拆解模糊观念 | "如何通过 X 做到 Y" |
| 观点复盘 | 行业洞察或个人复盘 | "我做了 X，结果是 Y" |
| 深度翻译 | 翻译海外优质内容，标注来源 | "一个国外 X 的 Y 年之旅" |

## 成功归因指南

每篇文章分析时必须判断：这篇文章效果好，是谁的功劳？

| 归因 | 含义 | 可复制？ |
|------|------|---------|
| 内容结构 | 文章的组织方式（层层递进、对比结构等） | ✓ |
| 表达策略 | 具体的写作手法（极简数学、反向承认等） | ✓ |
| 作者IP | 依赖作者个人影响力/粉丝基础/信誉 | ✗ |
| 热点事件 | 依赖特定热点/时效性 | ✗ |
| 平台红利 | 依赖平台流量窗口/算法倾斜 | ✗ |

只有归因于"内容结构"和"表达策略"的策略可进入策略库。

## 初始化

子 Agent 首次执行时，如 `{workspace}/deep-forge/strategy-memory.md` 不存在，从 `{baseDir}/references/strategy-memory-template.md` 复制创建。

## workspace 中 strategy-memory.md 的结构

Agent 需要维护 `{workspace}/deep-forge/strategy-memory.md` 的以下区域：

```
计数器（已处理文章总数 / 当前轮次）
文章类型定义表
已验证的策略库（策略条目按层级排列）
类型→策略匹配表
已知反模式表
最近输出记录
```
