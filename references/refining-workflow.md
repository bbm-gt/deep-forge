# Refining Workflow — 子 Agent 执行

## 触发

所有对标文章学完后，用户说"精炼策略库"。

## 子 Agent 输入

- 本文件
- workspace 中的 strategy-memory.md（完整策略库）

## 执行步骤

### 1. 过滤不可复制项

```
遍历所有策略：
  可复制性 ≠ "高可复制" → 移除（保留在原始策略库，不进入精炼版）
  成功归因中仅有"作者IP""热点事件""平台红利" → 移除
```

### 2. 合并功能重叠项

```
遍历剩余策略：
  两条策略功能描述 ≈ 相同？
    → 保留验证次数更高的那条
    → 将另一条的执行手法合并进来
    → 合并两者的常见错误
```

### 3. 按层级和验证排序

```
1. 🔴 核心策略（按验证次数降序）
2. 🟡 模式策略（按验证次数降序）
3. 🟢 情境策略（仅保留验证 ≥ 2 的，按验证次数降序）
```

### 4. 精简字段

精炼版每条只保留：功能、适用文章类型、执行方式（只留验证最充分的 3-5 种手法）、正确用法、常见错误、边界。

砍掉：来源、成功归因、可复制性（这些是学习阶段的元数据，写作不需要）。

### 5. 写入

写入 `~/.openclaw/workspace/deep-forge/refined-strategies.md`。

### 6. 输出精炼报告

```
精炼报告：
- 完整策略库：[N] 条 → 精炼后：[N] 条
- 移除不可复制：[N] 条（列出名称 + 原因）
- 合并重叠：[N] 对 → [N] 条
- 情境策略降级：[N] 条因验证不足（<2次）未进入精炼版
```

## 关键规则

精炼后写作模式自动优先读取 refined-strategies.md。精炼版是日常写作的策略源。
